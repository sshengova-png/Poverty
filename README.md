# Галерия Шенгова

Статичен сайт за онлайн галерия с картината „Лилава тишина с круша“ от
художник Селин Красимирова Шенгова.

Сайтът е подготвен да използва реалната снимка на картината. Запази снимката в
същата папка с име `selin-painting-photo.jpg`. Ако този файл липсва, сайтът ще
покаже резервната рисувана SVG версия `selin-kana-krusha.svg`.

## Как да отвориш сайта

1. Натисни два пъти файла `CLICK-TO-OPEN.html`.
2. Ако не се отвори автоматично, натисни големия бутон `Open Gallery`.
3. За отделните визитки отвори `business-cards.html`.
4. Ако искаш само визитките за сваляне или PDF, отвори `CARDS-ONLY.html`.
5. Ако искаш да изпратиш сайта на някого, изпрати заедно тези файлове:
   - `CLICK-TO-OPEN.html`
   - `index.html`
   - `business-cards.html`
   - `CARDS-ONLY.html`
   - `styles.css`
   - `script.js`
   - `selin-painting-photo.jpg` ако вече си добавила реалната снимка
   - `selin-kana-krusha.svg`

Визитките могат да се принтират или запазят като PDF от страницата
`business-cards.html`.
