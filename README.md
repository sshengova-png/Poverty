# Poverty

This repository contains a Bulgarian presentation about poverty:

- `poverty_presentation_google_slides.pptx` - Google Slides-friendly PowerPoint deck.
- `poverty_presentation_bg.pptx` - same deck kept under the original filename.
- `create_poverty_presentation.py` - generator script for rebuilding the deck.
- `open_in_google_slides.md` - quick steps for opening the deck in Google Slides.

The presentation covers material, intellectual, and spiritual poverty through
seven slides, using Bulgarian text, a modern dark blue / warm orange visual
theme, and standard Arial fonts for better Google Slides import.
